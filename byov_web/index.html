How to wire

  • Drag a sensor straight to a motor's FWD or REV bank (4 sockets each). Neurons have E/I inputs; motors have direction.
  • Wire colour = weight: blue 1x, green 2x, red 3x. Left-click cycles, right-click removes.
  • Meters M1–M3: one wire each, display only. Pot between motors = resting speed.
  • + / − beside the robot add/remove neurons (max 6, last-in-first-out).
  • Double-click a sensor to change type (LDR → IR → none).
  • Single-click LDR to cycle color channels: R, G, B, W (any color ambient)
