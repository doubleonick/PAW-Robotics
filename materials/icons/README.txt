PAW Icon Assets
===============

hierarchy_builder.ico / .png
  Icon for the Hierarchy Builder standalone launcher.

To create a desktop shortcut on Windows:
  1. Right-click hierarchy_builder.pyw in the project root
  2. Send to → Desktop (create shortcut)
  3. Right-click the shortcut → Properties
  4. Click "Change Icon" → Browse to this folder
  5. Select hierarchy_builder.ico → OK

The .pyw extension tells Windows to run the file with pythonw.exe,
which suppresses the console window. If double-clicking does nothing,
right-click → Open with → Python (pythonw.exe).

To find pythonw.exe:
  Usually at C:\Users\<you>\AppData\Local\Programs\Python\Python3XX\pythonw.exe
